* Question: If you create a constructor method to build a DVD by title then create a constructor method to build a DVD by category. Does JAVA allow you to do this?
- Java does not allow to create two constructors like that.
- Because both constructors have the same parameter type (String), they share the same signature - DigitalVideoDisc(String). Even if the parameter names are different (title or category), Java cannot distinguish between them. This will result in a duplicate constructor error.
- To use constructor overloading correctly, constructors must differ in the number or types of parameters, not just in parameter names. 

* Question: Is JAVA a Pass by Value or a Pass by Reference programming language?
- When a variable is passed to a method, Java always passes the copy of the value, not the original variable itself. 
+ For primitive types (int, float, ...), the actual value is copied. 
+ For objects, the value being copied is the reference (memory address) of the object. So the method can modify the objects' contents, but it cannot change the original reference to point to a different object.
-> Java is a pass-by-value programming language.
